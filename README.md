# Warehouse Inventory Manager

A Python command-line application developed for the Python Essentials course at VIT Bhopal. This system provides simple stock logging, automatic file initialization, and total inventory value calculations using standard CSV file handling.

## Features
- **CSV Data Persistence:** Automatically handles database file setup (`VITyarthiproject.csv`) and appends item logs securely without overwriting previous data.
- **Dynamic Valuation:** Employs positional `*args` unpacking to calculate total stock value dynamically.
- **Error Handling:** Built using standard `try-except` blocks to prevent runtime crashes during missing file operations or invalid user input.
